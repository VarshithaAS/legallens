# LegalLens

LegalLens is a web application that extracts and analyses text from legal documents such as PDF, DOCX, and TXT files.

## Live Demo

[Open LegalLens](https://legallens-0xrs.onrender.com/)

## Features

- Upload PDF, DOCX, and TXT documents
- Extract text from uploaded documents
- Generate document summaries
- Identify keywords and important clauses
- Highlight possible risks
- Generate downloadable reports

## Technologies Used

- Python
- Flask
- Gunicorn
- HTML, CSS, and JavaScript
- `python-docx`
- Render

## Run Locally

1. Clone this repository.
2. Open the project folder:

   ```bash
   cd legal-document-extractive-summariser-main
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the app:

   ```bash
   python app.py
   ```

5. Open the local URL displayed in the terminal.

## Deployment

This application is deployed on Render.

**Live URL:** [https://legallens-0xrs.onrender.com/](https://legallens-0xrs.onrender.com/)

## Note

Use sample, dummy, or redacted documents for testing. Do not upload confidential legal documents.
